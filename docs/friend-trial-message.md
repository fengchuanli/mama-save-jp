# 亲友试用发送话术

这个文档用于把 Mama Save JP 发给 5-10 个亲友试用。当前阶段只做人工邀请和人工记录，不做表单、登录、订阅或追踪链接。

## 使用前检查

发送前先确认：

- 本周没有明显过期或无法解释来源的优惠。
- 只引用当前站内已核验且仍有效的信息。
- 文案不承诺“必省钱”“最低价”“一定返”，只说明可以帮忙判断。
- 每次只发 1 个最匹配对方当前任务的入口，避免同时丢首页、优惠页、日历和多篇攻略。
- 每次只请对方完成 2-3 个小任务，避免像正式问卷。
- 收到反馈后记录原话，再填入 `docs/friend-feedback-checklist.md` 的模板。

## 先选一个入口

不要先问对方“整个网站怎么样”。先按对方这周最可能遇到的问题，选一个入口发出去：

| 对方当前状态 | 只发这个入口 | 让对方重点看 | 最值得追问 |
| --- | --- | --- | --- |
| 刚开始准备宝宝用品 | `/guides/newborn-shopping-list` | 第一批用品、先不囤什么、纸尿裤湿巾怎么少量试错 | 看完后是否更清楚第一批买什么 |
| 今天要补纸尿裤、湿巾或洗护 | `/deals` | 当前状态、官方来源、为什么值得看、什么情况跳过 | 是否能判断今天买还是等 |
| 在等楽天、西松屋、PayPay 等活动日 | `/calendar` | 当天确认、提前准备、先观察三种节奏 | 是否能分清什么时候再回来核对 |
| 看不懂积分、单片价或箱购规则 | `/guides/diaper-price-line` | 单片价、上限、尺码风险和不适合囤的情况 | 哪个字段最影响信任感 |
| 准备保育园或童装换季 | `/guides/nursery-entry-budget-items` | 园方清单、备用衣、午睡用品、姓名贴和先不急买的东西 | 是否少买一种可能买早或买错的东西 |
| 只是想知道这个站是干什么的 | `/` | 首页首屏、本周提醒、三块内容分工 | 30 秒内是否能看懂定位 |

## 微信或 LINE 私聊版

```text
我最近在整理一个给在日华人宝妈/宝爸用的小站，主要把日本母婴用品怎么买、什么时候买、哪些活动要注意，用中文整理出来。

我先不发你整站，只发一个最可能和你现在有关的入口。想请你帮我看 3-5 分钟，只做 3 件事：

1. 打开后，告诉我这个页面是不是和你现在的买东西场景有关。
2. 找一处你觉得有帮助、或让你不信任的地方。
3. 告诉我你下一步会继续看、收藏等下次用，还是直接关掉。

这个站不需要登录，也不会收集你的信息。现在还在早期，我最想知道的是：它能不能帮你判断今天买、等活动日，还是先跳过。

链接：
```

## 按场景替换首句

私聊时可以把开头第二句替换成下面任意一句，再只贴对应链接：

- 刚开始准备：我猜你现在最需要的不是看优惠，而是先把第一批用品和不急囤的东西分清楚。
- 今天要买：我猜你更需要先判断今天这单能不能买，所以我先发“本周值得买”入口。
- 等活动日：我猜你可能不急着今天下单，所以我先发省钱日历，帮你看最近哪些节点值得等。
- 看不懂规则：如果你主要卡在积分、单片价或箱购要不要囤，我先发这篇判断规则。
- 准备保育园或童装换季：如果你最近在看入园清单或换季衣服，我先发保育园准备入口，帮你排除容易买早的东西。
- 只想了解本站：如果你只是想先知道这个站能不能用，我先发首页；你看完只要告诉我下一步最想点哪一类。

## 首页转接话术

只有在对方没有明确购物任务、或只是第一次听说 Mama Save JP 时才发首页。对方回复后不要在同一轮继续塞多个链接，先按下面规则选下一轮唯一入口：

| 对方回复 | 下一轮入口 | 下一轮追问 |
| --- | --- | --- |
| 我刚开始准备，不知道该买什么 | `/guides/newborn-shopping-list` | 看完后，哪些东西会先买或先不买？ |
| 我现在就要补货 | `/deals` | 能不能判断今天买、等下一场，还是跳过？ |
| 我想等活动再买 | `/calendar` | 哪个日期需要你之后再回来核对？ |
| 我看不懂规则或价格 | `/guides/diaper-price-line` | 哪个字段最影响你信不信这个判断？ |
| 我在准备保育园或换季 | `/guides/nursery-entry-budget-items` | 有没有少买一种可能买早或买错的东西？ |
| 我还是没看懂这个站 | 继续记录原话 | 30 秒内最不清楚的是适合谁、做什么，还是先点哪里？ |

## 跟进追问

对方回复后，只追问 1-2 个最关键问题：

1. 这个入口是不是你现在最想看的？如果不是，你更想先看什么？
2. 看完后你会买、等，还是跳过？
3. 哪一句话或哪个字段让你担心信息不准？
4. 你会把这个入口发给同在日本的朋友吗？

## 反馈处理规则

- 如果反馈指向过期、来源不清或价格表达过度确定，优先修信任问题。
- 如果 3 人以上都找不到入口，再调整首页或导航结构。
- 如果只是单个主题缺内容，先记录到下一轮攻略或优惠数据任务。
- 不因为 1 条反馈就做大范围改版。
