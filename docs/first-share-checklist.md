# 首次分享执行清单

这个清单用于把 Mama Save JP 第一次发到小红书、朋友圈或小范围群聊前做人工检查。当前阶段只验证用户是否愿意打开、收藏、回访和转发，不做表单、登录、付费群、抽奖或复杂追踪。

## 适用场景

- 准备把站点发给 5-10 个在日华人宝妈/宝爸。
- 准备从 `docs/growth-copy-bank.md` 里挑 1 条文案发布。
- 准备把某个页面发到微信群、LINE 群或朋友圈。
- 收到亲友反馈后，想判断下一步是改内容、改入口，还是继续收集样本。

## 发布前 10 分钟检查

每次只选一个主入口，不要同时推首页、优惠、日历和多篇攻略。

1. 选定目标用户：孕期、0-6 个月、7-18 个月、19-36 个月，或刚来日本的新手家庭。
2. 选定一个入口：`/`、`/deals`、`/calendar`，或 1 篇具体攻略。
3. 写下这次入口要解决的一个问题，例如“第一批买什么”“今天要不要补货”“要不要等活动日”。
4. 打开对应页面，确认标题、首屏和主要卡片能解释“适合谁”和“怎么判断”。
5. 如果文案提到优惠，只引用站内 `dataStatus: verified` 且 `availabilityStatus: active` 的内容。
6. 如果不确定优惠是否仍有效，就改发攻略或日历解释，不要发“本周值得买”。
7. 删掉夸张词：必买、稳赚、闭眼入、全网最低、一定返、错过就亏。
8. 在文案末尾只放一个链接，避免用户不知道先点哪里。
9. 准备 1 个追问问题，发布后只追问最关键的反馈。

## 单入口发布决策

发布前先把下面三栏写清楚，再去选 `docs/growth-copy-bank.md` 里的文案。选不出来时，宁可发攻略，不要发多个入口让对方自己找。

| 这次对方最可能的问题 | 只发这个入口 | 只追问这一个问题 |
| --- | --- | --- |
| 刚开始准备，不知道第一批买什么 | `/guides/newborn-shopping-list` | 看完后，哪些东西你会先买或先不买？ |
| 纸尿裤、湿巾或洗护快用完 | `/deals` | 你能不能判断今天买、等下一场，还是跳过？ |
| 不急着买，想等楽天、西松屋或 PayPay 节点 | `/calendar` | 哪个日期或活动需要你之后再回来核对？ |
| 看不懂积分、单片价或箱购 | `/guides/diaper-price-line` | 哪个字段最影响你信不信这个判断？ |
| 准备保育园或童装换季 | `/guides/nursery-entry-budget-items` | 有没有帮你减少会买错的东西？ |
| 只是介绍 Mama Save JP 是什么 | `/` | 30 秒内能不能看懂这个站适合谁？ |

## 发布文案最后检查

- 标题只对应一个场景，不把“清单、优惠、日历、攻略”全部塞进同一条。
- 正文最多解释一个判断方法，例如单片价、活动日、清单顺序或跳过条件。
- 链接前一句要说明为什么点这个入口，而不是泛泛写“网站在这里”。
- 追问问题要能用一句话回答，方便对方直接在私聊或评论里回。
- 如果对方回复了新的购买需求，下一轮再换入口，不在同一轮追加多个链接。

## 只发首页时的转接规则

首页只用于第一次介绍 Mama Save JP 是什么，不用于同时验证优惠、日历和攻略是否都好用。发首页后先问“30 秒内能不能看懂适合谁、先点哪里”，再按对方自己说出的下一步，安排下一轮唯一入口。

| 对方看完首页后的反应 | 下一轮只发 | 不要立刻做什么 |
| --- | --- | --- |
| 说自己正在列第一批清单 | `/guides/newborn-shopping-list` | 不马上追加 `/deals` |
| 说家里快没纸尿裤、湿巾或洗护 | `/deals` | 不让对方自己翻全部攻略 |
| 说想等活动或不急着买 | `/calendar` | 不把单个过期活动当推荐 |
| 说看不懂积分、单片价或返点 | `/guides/diaper-price-line` 或 `/guides/rakuten-5-0-mama-shopping` | 不继续发首页截图解释 |
| 说在准备保育园或换季衣服 | `/guides/nursery-entry-budget-items` | 不先发泛促销文案 |
| 说看不懂站点定位 | 继续记录首页反馈 | 不马上改全站导航，先累计相似反馈 |

## 反馈处理

- 如果 3 人以上说看不懂站点用途，优先改首页第一屏或入口文案。
- 如果 3 人以上担心优惠过期，优先复查 `/deals` 和来源说明。
- 如果 3 人以上只收藏攻略、不看优惠，下一轮优先补攻略厚度和内链。
- 如果 3 人以上愿意转发某一页，保留原入口，不急着改版。
- 如果反馈只是单个主题缺内容，记录到后续攻略或优惠数据任务，不做大范围重构。

## 不做事项

- 不用未经确认的截图或价格吸引点击。
- 不承诺一定省钱或固定返现。
- 不把抽选活动写成确定优惠。
- 不在早期收集手机号、宝宝生日、家庭收入或详细消费记录。
- 不因为单条反馈马上改导航、设计或核心结构。
